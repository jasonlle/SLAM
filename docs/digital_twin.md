# A digital twin of the SLAM lab and VNA rig

*Companion to `slam/sim/digital_twin.py` (Phase A simulator). Binding formats are in `docs/CONTRACT.md`.*

## 1. What "digital twin" means for this project

For us a digital twin is **a parametric electromagnetic + geometric model of the lab and the measurement rig that emits the same files the real collector does**: per-sweep CSVs with `Frequency_Hz, S11_re, S11_im, S21_re, S21_im, S22_re, S22_im`, a `manifest.csv`, and a `session_info.json`. Everything downstream (`analyze_sensitivity`, the zone classifier, the position regressor) must run on a simulated session without knowing it is simulated.

"Parametric" is the important word. The twin is not a photo-realistic copy of the room; it is a small set of physically meaningful knobs (antenna position/tilt/pattern, wall/floor/ceiling reflectivity, person RCS and blockage, cable loss, noise, drift) that we can (a) set from tape-measure values, (b) *fit* to the real empty-room and person-present sweeps, and (c) turn to answer "what if" questions that would take an afternoon of re-rigging in the lab. The twin lives at three fidelity levels (Section 3); all three share the same output writer so the ML pipeline never changes.

## 2. Simulation options surveyed

| Tool | Method | Cost / licence | Learning curve | What it would give us |
|---|---|---|---|---|
| **numpy image method** (Phase A, this repo) | Friis + first-order images + point scatterer | free | hours | Pipeline testing, feature sanity, sensitivity/what-if studies, synthetic pre-training at low fidelity |
| **NVIDIA Sionna RT** | Differentiable ray tracing (shooting-and-bouncing + exhaustive), built on Mitsuba 3 / Dr.Jit | free, Apache-2.0, `pip install sionna-rt` | days (Blender scene + Python) | Site-specific multipath with materials, diffraction, scattering; runs on Colab GPU; gradients let us *calibrate* materials/antenna poses against measurements |
| **MATLAB `raytrace` / `siteviewer`** (Antenna + Communications Toolbox) | SBR ray tracing on STL/glTF indoor scenes, ITU-R P.2040 materials | university licence | days | Same physics class as Sionna with a GUI; `comm.RayTracingChannel` gives CIR/CFR; convenient if the team already lives in MATLAB |
| **Remcom Wireless InSite** | X3D GPU ray tracer, diffuse scattering, MIMO | commercial (academic pricing) | days-weeks | Industry-standard propagation "digital twins"; overkill unless the lab already has a seat |
| **Ansys HFSS (FEM) + SBR+**, **CST Studio Suite** | Full-wave (FEM / FIT) plus asymptotic SBR+ for electrically large scenes | commercial, expensive; student versions limited in size | weeks | Antenna near field, S11 detuning by nearby metal/body, exact panel pattern; SBR+ for the room |
| **FDTD: gprMax, openEMS, MEEP** | Full-wave time domain, open source (GPL/MIT), Python front-ends, GPU (gprMax: CUDA/OpenCL/Metal) | free | weeks | Whole-room full-wave at 900 MHz is feasible (~4 M cells at λ/10) but a dielectric human phantom needs ~4 mm cells (λ/10 *inside* tissue) which blows up the mesh; best for a sub-volume (antenna + cabinet, or the phantom alone for RCS) |
| **MoM (FEKO, NEC-2/4nec2)** | Surface currents | FEKO commercial; NEC free | days | Antenna + cabinet interaction, phantom RCS with a surface-equivalent body (used by the Politecnico di Milano DFL group to validate their body model) |

Sources: Sionna RT documentation ([nvlabs.github.io/sionna](https://nvlabs.github.io/sionna/rt/tutorials/Introduction.html)) and paper ([arXiv:2303.11103](https://arxiv.org/abs/2303.11103)); MATLAB [`raytrace`](https://www.mathworks.com/help/antenna/ref/txsite.raytrace.html), [Indoor MIMO-OFDM link using ray tracing](https://www.mathworks.com/help/comm/ug/indoor-mimo-ofdm-communication-link-using-ray-tracing.html) and [`buildingMaterialPermittivity`](https://www.mathworks.com/help/antenna/ref/buildingmaterialpermittivity.html); [Remcom Wireless InSite](https://www.remcom.com/wireless-insite-propagation-software) and its use for wireless digital twins ([arXiv:2410.14620](https://arxiv.org/html/2410.14620v1)); [Ansys HFSS SBR+](https://www.ansys.com/blog/new-hfss-sbr-technology-in-ansys-2021-r2); [gprMax](https://gprmax.org/); a comparison of open-source FDTD solvers ([arXiv:2510.04262](https://arxiv.org/abs/2510.04262)); overview of open-source EM tools ([EpsilonForge](https://www.epsilonforge.com/post/open-source-electromagnetics/)).

Two findings from the sim-to-real literature shape the recommendation. First, in a study calibrating Sionna against 1,664 real 4G/5G measurements, *solver hyper-parameters (path depth, sample count) had "immaterial" effect while antenna locations and orientations proved decisive*; the sim-to-real crossover error was about twice the real-data baseline until poses were optimised ([arXiv:2507.19653](https://arxiv.org/html/2507.19653)). Second, for synthetic pre-training, *fidelity beat scale*: a 53 k-sample Sionna dataset with calibrated base-station parameters transferred better than a 274 k-sample uncalibrated one, and pre-training halved real-world localization error ([Bridging the sim-to-real gap in RF localization](https://www.sciencedirect.com/science/article/pii/S1566253525011662)). For indoor Wi-Fi RSS fingerprinting, Bayesian optimisation of wall materials plus a per-transmitter offset brought Sionna RT to 5-7 dB MAE against measurements and gave 3.05 m error from synthetic-only training ([arXiv:2608.23901](https://arxiv.org/html/2608.23901)). The lesson: **measure the rig geometry carefully, calibrate a few material/RCS parameters, and do not chase solver fidelity**.

## 3. Which fidelity is needed for what

**(a) Analytic image method + point-scatterer person (Phase A).** Direct path, six first-order wall/floor/ceiling images, a cylinder for blockage and a point scatterer with a bistatic RCS. Runs 150 sweeps in a second. Sufficient for: exercising the collector/analysis/training code before real data exists; checking that "complex difference from empty" is the right feature; sensitivity studies (how big is Δ at each grid point relative to noise, which S-parameter is informative where); and coarse what-ifs (antenna height, tilt, IF bandwidth). Not sufficient for absolute fidelity: no cabinets, benches, door, second-order bounces, diffraction, or realistic antenna pattern.

**(b) Ray tracing with a human phantom (Phase B, Sionna RT).** A Blender box with the two metal cabinets, benches and the drop-ceiling grid as PEC, ITU-R P.2040 materials for drywall/concrete/tiles, the panel antenna as a measured or `cos^n`-fitted pattern, and the person as a dielectric cylinder/ellipsoid mesh with tissue properties. Gives site-specific multipath ripple, correct blockage/diffraction and cabinet reflections. Sufficient for domain-randomised pre-training (randomise person size/position, materials, cable phase, antenna pose within measurement tolerance) and sim-to-real transfer experiments. Ray tracing with a human mesh is exactly the device-free-localisation regime studied at 2.4 GHz by the HOLDEN project ([EM body model for DFL](https://arxiv.org/html/2405.09558v1)).

**(c) Full-wave (HFSS/CST/FDTD).** Only needed if we care about the antenna itself: S11 detuning when the person stands within ~1 m of a panel (`near_ant1`), coupling to the metal cabinet under the tripod, or an accurate pattern of the specific L-com panel. These are one-off numbers that can be folded into the twin as parameters. Recent work does show fast full-wave RSS maps for DFL pre-measurement validation ([arXiv:2605.04958](https://arxiv.org/abs/2605.04958)), but it is not on our critical path.

## 4. Modelling the person

**Dielectric properties.** At 900 MHz muscle has ε_r ≈ 55 and σ ≈ 0.94 S/m, skin ε_r ≈ 41, σ ≈ 0.87 S/m (Gabriel 1996, tabulated in the [IFAC-CNR tissue database](https://niremf.ifac.cnr.it/tissprop/) and [IT'IS](https://itis.swiss/virtual-population/tissue-properties/database/dielectric-properties)). The penetration depth is a few centimetres, so a torso is an *opaque, lossy, strongly reflecting* object: the normal-incidence reflection coefficient of a half-space with ε_r = 55 is |Γ| ≈ 0.76. A homogeneous vertical cylinder (radius 0.15-0.2 m, height 1.7-1.8 m) or an ellipsoid with muscle properties is the standard phantom for propagation work; a 2-D absorbing sheet is the Politecnico DFL model.

**Radar cross-section.** Tabulated "typical" RCS of a human is about 1 m² (0 dBsm) ([Wikipedia RCS table](https://en.wikipedia.org/wiki/Radar_cross_section)). Measurements and FDTD models at UHF/L-band spread over roughly 0.5-2 m² (−3 to +3 dBsm) depending on aspect angle, posture and polarisation, with vertical polarisation on a standing person near the upper end ([UWB human RCS measurements](https://ieeexplore.ieee.org/document/6229134/); [ARL human body signature models](https://apps.dtic.mil/sti/tr/pdf/ADA473937.pdf); [directionally resolved human RCS](https://wides.usc.edu/Updated_pdf/abbasi2020measurement_review.pdf)). We use 1 m² bistatic and monostatic as defaults and treat RCS as a calibration parameter (±10 % jitter per sweep).

**Body shadowing.** Sub-GHz blockage is mild because the body is only ~1 wavelength wide. A 433/868 MHz device-free localisation study with tripod-mounted nodes reports 4-7 dB attenuation when the person is on the link and 3-4 dB changes on links the person is *not* blocking, purely from multipath ([Sub-GHz passive radio mapping](https://www.mdpi.com/2076-3417/10/18/6183)). At 2.4 GHz the sheet model gives 7-17 dB depending on offset from the LOS ([arXiv:2405.09558](https://arxiv.org/html/2405.09558v1)); at 28 GHz and above blockage reaches 20-30 dB. Our default `blockage_db = 5` with a Gaussian roll-off over 0.6 Fresnel radii is therefore in range; note that with antennas at 2.7 m the direct ray passes ~1 m above the head, so in our geometry the person mostly blocks the **floor bounce** and adds a scattered term rather than shadowing the LOS. That is a testable prediction (Section 6).

**Micro-motion.** Breathing moves the chest 4-12 mm and standing sway is 1-3 cm; at λ = 0.33 m a 2 cm path change is ~0.4 rad on the scattered component. This is exactly the "person jitter" in the twin (position σ = 3 cm, RCS ±10 %), and the ACES breathing-RCS study ([Riverpublishers](https://journals.riverpublishers.com/index.php/ACES/article/download/10313/8629/32035)) supports treating it as an RCS/phase modulation rather than re-meshing.

## 5. Modelling the rig

* **Panel pattern.** A `cos^n` power pattern with directivity 2(n+1): n = 2 gives 7.8 dBi, matching the ~8 dBi L-com panel. E- and H-plane exponents are separate so the panel's unequal beamwidths can be mimicked; the back lobe sits at a front-to-back floor (15 dB). If the datasheet pattern is available, replace `panel_gain` with an interpolated table; the rest of the code is unchanged.
* **Tilt and azimuth** come from `config.ANTENNAS` (default azimuth aims at the square centre, tilt is a fixed −30°, antennas at (−0.5, −0.5, 2.7) and (4.5, 4.5, 2.7) m); `--set antenna_z_override_m=… antenna_tilt_override_deg=…` supports placement what-ifs.
* **Polarisation.** Both antennas vertical, person vertical cylinder: co-polar, no mismatch factor. The optional Fresnel reflection model applies TE coefficients to walls and TM to floor/ceiling, which is the correct assignment for a vertically polarised rig.
* **Cabinets and benches.** Not in Phase A. In Phase B they become PEC boxes; a 1.5 m metal cabinet directly under each antenna is the single most important scene object to add because it sits in the antenna's near/Fresnel region.
* **Cables, connectors, mismatch.** Folded into a static two-port loss (`system_loss_db`, default 10 dB: ~0.3 dB/m coax each side, connectors, pattern/efficiency shortfall) and a static S11/S22 term (−20 dB with a 1.5 dB ripple whose period comes from the coax round-trip electrical length). These are the first parameters to fit to Dataset v1: the empty-room |S21| level pins `system_loss_db`; the S11 ripple period pins cable length.
* **Nuisances.** Complex Gaussian noise at −70 dB on every S-parameter, 0.02 dB trace-to-trace gain jitter, and slow drift (0.02 dB amplitude over a 30 min period, 1°/h phase). Drift multiplies the −20 dB static S11/S22 term, so it is deliberately small: cold-start values (`--set drift_amp_db=0.15 --set drift_phase_deg_per_hour=6`) produce a −52 dB S11 "delta" on an *empty* room after 8 min, which swamps the person's S11/S22 signature. The real rig's drift must be measured (interleave `empty` sweeps through the session) before the S11/S22 conclusions of the twin are trusted.
* **Room surfaces.** Constant coefficients (walls −0.6, floor −0.7, ceiling −0.4), or Fresnel half-space coefficients from ITU-R P.2040 (plasterboard ε_r = 2.73, concrete 5.24, ceiling board 1.48) ([ITU-R P.2040](https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.2040-3-202308-S!!PDF-E.pdf)). The drop ceiling, 10 cm above the antennas, is the most uncertain surface: a half-space model over-estimates its reflection, and its metal grid is a periodic scatterer.

## 6. Validation plan

1. **Empty-room level and ripple.** Compare mean |S21| (dB) over the band, sim vs. measured; fit `system_loss_db`. Compare the detrended |S21| vs. frequency (ripple amplitude and dominant period via FFT of the complex sweep = pseudo delay profile); adjust `refl_floor`/`refl_ceiling` and, in Phase B, the cabinets. Compare S11/S22 ripple period to fit `cable_m`.
2. **Person deltas.** For `center`, the four corners and `near_ant1/2`, compare mean |Δ| (dB) and the detectability ratio from `analyze_sensitivity` between sim and real. Fit `rcs_bistatic_m2`, `rcs_monostatic_m2`, `blockage_db` by least squares over these labels; keep the fit small (3-4 parameters) to avoid over-fitting, as the RSS augmentation work did with materials plus a per-transmitter offset.
3. **Prediction test.** The twin predicts that S11/S22 are more informative than S21 near the antennas and that a person at `C1`/`A3` (off the diagonal) produces a much smaller S21 delta than on the diagonal. Check both in Dataset v1 before trusting the twin for what-ifs.
4. **Gap metric.** Report (i) empty-level error in dB, (ii) ripple correlation, (iii) RMSE in dB between simulated and measured mean |Δ| across labels, and (iv) the transfer gap: zone-classifier accuracy trained on sim and tested on real, versus real-on-real, versus sim-pretrained + real-fine-tuned.
5. **Using sim data in the paper.** Pre-training / augmentation (randomise person size, position jitter, materials, drift); ablation of antenna placement (height, tilt, corner vs. mid-wall, lower antennas so the LOS is shadowed) reported as detectability maps; and a "what-if" section that only the twin can answer, e.g. whether lowering both antennas to 1.6 m turns the weak scatter-only signature into a shadowing signature (the Phase A twin says the center |ΔS21| changes by less than 1 dB, because the floor bounce compensates, which is itself worth checking).

## 7. Phased plan

* **Phase A (now): numpy image-method twin.** Delivered in `slam/sim/digital_twin.py`. `python -m slam.sim.digital_twin --session sim_demo --labels all --n 5 --seed 0` writes a 150-sweep session; `--sweep-plot` gives a one-figure sanity check; `--set field=value` overrides any `TwinParams` entry. With the default parameters (`--seed 0`): empty |S21| ≈ −43 to −44 dB, center |ΔS21| ≈ −55 dB against a −72 dB reference residual (detectability ratio ≈ 6), |ΔS11| ≈ −52 dB at `near_ant1` / `A1` and |ΔS22| ≈ −51 dB at `E5`, versus ≈ −60 dB for both at `center`. The room box defaults to (−2, −1, 0)–(6, 5, 2.8) m from `config.ROOM`.
* **Phase B (October): Sionna RT scene on Colab GPU.** Model the room in Blender (box, cabinets, benches, door) and export through the Mitsuba-Blender add-on; assign ITU materials; place the two `PlanarArray` single-element antennas with the `cos^n` or measured pattern at the config poses; add a dielectric-cylinder person mesh with a custom `RadioMaterial` (ε_r = 55, σ = 0.94); run `PathSolver` with `max_depth` 3-5, specular reflection and diffraction on, and take `Paths.cfr()` at the 201 sweep frequencies. Wrap the output in the same `Sweep`/`sweep_to_csv`/manifest writer (only `Twin.sweep` is replaced). Add the static S11/S22 and noise/drift terms from Phase A on top.
* **Phase C (November, optional): calibration against Dataset v2.** Use Sionna's differentiability or a small Bayesian search to fit wall/floor/ceiling materials and antenna pose within tape-measure tolerance; fit RCS/blockage from the person labels; then regenerate the synthetic set and report the gap metrics before and after calibration.

Known limitations of Phase A to state explicitly: first-order reflections only (real ripple will be richer), no cabinets/benches/door, isotropic point scatterer with no aspect dependence, single-frequency Fresnel radius for blockage, no near-field antenna detuning, and materials extrapolated slightly below the 1 GHz lower bound of the ITU-R P.2040 tables.
